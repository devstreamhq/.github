# Getting help

Pick the place that fits, and you'll get an answer faster.

- **A question**: ask in [Discussions Q&A](https://github.com/devstreamhq/devstream/discussions/categories/q-a). The [wiki](https://github.com/devstreamhq/devstream/wiki) may already have the answer.
- **A bug**: open an issue in the repository where you found it.
- **A problem with a listed repo**, such as spam or a dead link: [report the entry](https://github.com/devstreamhq/devstream/issues/new?template=report-entry.yml).
- **A security issue**: don't open a public issue. Follow the [security policy](SECURITY.md) and report it privately.
