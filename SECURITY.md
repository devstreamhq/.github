# Security policy

If you've found a security vulnerability in any DevStream repository, please report it privately. Don't open a public issue, discussion or pull request.

## How to report

1. Go to the **Security** tab of the affected repository.
2. Select **Report a vulnerability**.
3. Describe the issue, how to reproduce it and what an attacker could do with it.

This uses GitHub's private vulnerability reporting, so only the maintainers can see your report. We'll reply in the advisory and keep you posted while we work on a fix.
